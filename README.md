# blackcoffe
Sistema de pedidos 
Esta solución, la cual ayuda a llevar registro de la ordenes con sus productos y los cobros de una cafetería.
Este proyecto utiliza React para el Frontend, usa una base de datos SQL y Express para el backend.
El sistema orbita alrededor de 5 elementos principales, los clientes, que corresponden a los clientes del centro comercial, los productos, que tienen un valor y un nombre,  las ordenes, que son creadas bajo un usuario específico y se les agrega productos a lo largo del tiempo, y los abonos, que se usan para registrar los cobros efectuados en cada orden.
Una vez se hacen abonos por el total de la orden esta es archivada en la pestaña de ordenesPagas.
